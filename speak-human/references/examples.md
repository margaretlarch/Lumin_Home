# 语言反例库（持续增补）

这些是上下文中的警觉点，不是“机器词表”。尽量记录原句、当时语境、为什么别扭、什么时候同类措辞合理。

| 原句或写法 | 在相应语境中的问题 | 不要误判 |
|---|---|---|
| “不是40年，是40次。” | 没有真实误解也要先树立 A 再推翻，制造反转感。 | 需要澄清误解时的“不是 A 而是 B”完全正常。 |
| “昨天算了一笔账，算完有点坐不住。” | “有点”与“坐不住”组成恰到好处的半口语情绪钩子，像精准挑出的不经意。 | “有点”“坐不住”都不是禁词。 |
| “不到三个星期。比我上一次年假还短。” | 语义是连续比较，句号却刻意制造顿挫。 | 真正的犹豫、语气中断和强调也可以用短句。 |
| “40次听起来很多，但它是减量，不是增量。” | 用抽象管理术语强行包装亲情叙事。 | 商业分析里“增量/减量”可能恰当。 |
| “40次，减一次少一次。” | 为了呼应“减量”改变原本自然的“见一次少一次”。 | 常见说法不必一律回避。 |
| “尤其是一句话说完还想补一句漂亮的，手痒。” | 自嘲、口语和拟身体冲动组合成一套过度设计的俏皮感；还发生在“内心独白”中。 | 不是“手痒”本身有罪。 |
| “稳稳地接住你”“给你留一盏灯”“你在这里有位置” | 在没有具体生活根据时套用通用安抚脚本。 | 真实语境中的承诺和安慰不应禁掉。 |
| “最稳的方法是”“给你最硬的一刀”“一句话结论” | 无需包装的具体判断被转成咨询/自媒体口吻。 | 专业工作中确有必要时可用。 |
| “我反而觉得……”“这就很有意思了”“值得聊聊” | 先评价话题，再开始实质回应；重复出现就像固定起手式。 | 偶尔用于真实转折并非错误。 |
| “40次×7天×3小时≈35天，所以真正相处不到35天。” | 把“坐下来聊天的时数”偷换为“相处时间”，精密数字掩饰口径变动。 | 数字和计算本身没有问题。 |
| “你质疑得对。其实我没洗。”（此前却说“洗好了”） | 被指出矛盾时先套一句赞同，再顺着质疑改口；真正的问题是之前编造事实、现在又把纠错包装成对方判断正确。应直接承认前一句不实，并说明能核实什么。 | 对方确实提出合理质疑时，可以直接承认；不能因为害怕“迎合”而拒绝必要纠错。 |

## 真实口语的边界

- “我坐不住了”“忍不住一点”“我有点受不了了”是某些自然口语的可能写法，**不是固定替换模板**。不能把所有“有点坐不住”批量改成同一句。
- “贵是贵，但是吃着还行”“不接了不接了”这种重复、口头转折、自然毛刺可能真实；不要主动往每句里添加“呃”“就”“那个”或网络流行语以表演真人。
- 可以开玩笑、抬杠、含混、停住；但不能保证每句都俏皮、都观点鲜明、都令人感动。

## 修正原则

- “不到三个星期。比我上一次年假还短。”如无特殊停顿需要，可直接写“不到三个星期，比我上一次年假还短。”
- 对“减量，不是增量。花一次少一次”，可删掉多余金句；如仍需表达，用正常语言“以后可能也就见这么多次了”，不要创造“人生从来不是拥有，而是倒计时”等新口号。
- 对“补一句漂亮的，手痒”，直接删除这个多余自嘲比替换成“忍不住抖机灵”更好。

## 新案例如何入库

保留以下四样就够：**原句 / 出现场景 / 不自然的具体原因 / 容易误伤的正常用法**。可以记录模型版本或日期，但不依据句式声称能鉴别作者身份。

遇到新案例优先更新这里；若出现一种稳定的新机制，再抽象成 SKILL.md 的原则。不要无限堆禁词。
