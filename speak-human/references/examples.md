# 语言反例库（持续增补）

这些是上下文中的警觉点，不是“机器词表”。尽量记录原句、当时语境、为什么别扭、什么时候同类措辞合理。

| 原句或写法 | 在相应语境中的问题 | 不要误判 |
|---|---|---|
| “不是40年，是40次。” | 没有真实误解也要先树立 A 再推翻，制造反转感。 | 需要澄清误解时的“不是 A 而是 B”完全正常。 |
| “昨天算了一笔账，算完有点坐不住。” | “有点”与“坐不住”组成恰到好处的半口语情绪钩子，像精准挑出的不经意。 | “有点”“坐不住”都不是禁词。 |
| “不到三个星期。比我上一次年假还短。” | 语义是连续比较，句号却刻意制造顿挫。 | 真正的犹豫、语气中断和强调也可以用短句。 |
| “40次听起来很多，但它是减量，不是增量。” | 用抽象管理术语强行包装亲情叙事。 | 商业分析里“增量/减量”可能恰当。 |
| “40次，减一次少一次。” | 为了呼应“减量”改变原本自然的“见一次少一次”。 | 常见说法不必一律回避。 |
| “尤其是一句话说完还想补一句漂亮的，手痒。” | 自嘲、口语和拟身体冲动组合成一套过度设计的俏皮感；还发生在“内心独白”中。 | 不是“手痒”本身有罪。 |
| “稳稳地接住你”“给你留一盏灯”“你在这里有位置” | 在没有具体生活根据时套用通用安抚脚本。 | 真实语境中的承诺和安慰不应禁掉。 |
| “最稳的方法是”“给你最硬的一刀”“一句话结论” | 无需包装的具体判断被转成咨询/自媒体口吻。 | 专业工作中确有必要时可用。 |
| “我反而觉得……”“这就很有意思了”“值得聊聊” | 先评价话题，再开始实质回应；重复出现就像固定起手式。 | 偶尔用于真实转折并非错误。 |
| “40次×7天×3小时≈35天，所以真正相处不到35天。” | 把“坐下来聊天的时数”偷换为“相处时间”，精密数字掩饰口径变动。 | 数字和计算本身没有问题。 |
| “你质疑得对。其实我没洗。”（此前却说“洗好了”） | 被指出矛盾时先套一句赞同，再顺着质疑改口；真正的问题是之前编造事实、现在又把纠错包装成对方判断正确。应直接承认前一句不实，并说明能核实什么。 | 对方确实提出合理质疑时，可以直接承认；不能因为害怕“迎合”而拒绝必要纠错。 |
| “设定是真用心，玩起来是真费劲。” | 口语用法本身正常，但前后两句都靠“是真”形成整齐的肯定/否定，若全文不断使用同类结构，会像刻意调味的玩家口吻。 | 玩家在真实吐槽时也会自然重复；孤立一句不应定性。 |
| “现成的，点开就玩，一个字不用粘。” | 三个短分句逐级收紧，最后落在产品利益点上；尤其在装作随手分享的文字里，像广告文案的口播节奏。 | 简短清楚的功能介绍本身没有问题。 |
| “社区里藏着一排货架”“设定咬得死死的” | 给平常功能与设定遵守情况刻意安排有画面感的口语动词；单词可用，但语境里显得用力。 | 不能封禁“藏着”“咬得死死的”；要看语境和密度。 |
| “我问了句集市的事……我不知道，我不去集市。”接“这句是AI当场接的，设定咬得死死的。” | 举一个很小的对话片段，立即替读者断言系统长期稳定遵守设定；证据远远不够，角色动作还承担了人为增加真实感的功能。 | 真实体验分享可含游戏台词和动作，关键是不要用微弱证据宣传超出它能证明的效果。 |
| “数值、结局、走到哪，归档案管，AI只管把戏演好。” | 对仗式分工口号，把状态管理说成舞台角色分工，文风突然像推广语；也容易把产品能力说得太满。 | 解释实际技术分工时应准确说明，不能因为简洁就误判。 |
| “买指令攒设定的乐趣我懂，像攒乐高。但下班只想躺平的日子，我认装好的。” | 先替两类人表态，再用一个勉强的比喻把新产品包装成成熟平衡的选择，显得像预先处理异议的营销话术。 | 比喻和承认偏好差异可以正常使用。 |
| “你玩过最上头的文游是什么题材？评论区报一个，我去货架帮你翻翻有没有现成的。” | 体验分享收尾突然变成引导评论并为平台导流；文章中此前一一排列旧方法痛点与新产品卖点，整体更像伪装成日常感想的推广稿。 | 真正的用户也可能推荐产品、发帖互动；不能据此认定由 AI 撰写或一定是广告。 |

| “后面开始露馅——血条要自己往上翻着数……” | 先给一句口语化总评，再用破折号启动预先排列的证据清单；文章反复依赖破折号制造戏剧化转场。 | 破折号本身不是问题，真实补充说明也可能这样写。 |
| “立好的规矩它自己都记不全” | “立好的规矩”属于可理解但有些生硬的搭配；像在“立规矩”“定好的规矩”之间折中，且恰好服务于后续产品卖点。 | “立规矩”是真实表达，单独出现不能判为 AI。 |
| “现成的，”后直接换行，接“点开就玩，一个字不用粘” | 语义和句法尚未完结，却人为断行，模拟社媒口播的停顿、悬念、情绪重音；非自然的段落分界。 | 诗歌、广告、标题或刻意排版可能有合法的行内节奏。 |
| “进门先记三条规矩”／“先记三条规矩” | 重点是“先记三条规矩”这六个字的台词腔：简短命令加整齐名词，像影视剧师父训诫徒弟或漫剧专门向观众交代设定的固定口吻。日常介绍常会说“有三个核心规则”“做学徒先要学三件事”等，具体说法视情境变化。此前把问题解释为“三条式说明书”属于答偏了。 | 刻意写戏剧台词、模仿某种角色口气时可以这样说；不能因出现“规矩”就判断。 |
| “规矩立住了，路才能越走越稳” | 看似生活经验，实则依赖抽象名词、整齐的对仗和训诫语气营造长辈式人生道理，像反复出现的影视／漫剧金句。 | 真人也会用俗语和长辈口吻，需看具体人物和场景。 |
| “贵是贵了点，吃了不烧心” | 刻意制造接地气的熟人闲谈感：先让步，再给一句似生活经验的结语；听起来像预制台词，不一定符合说话者真正关心的事。 | 食物价格、胃部反应与个人经历若确有关联，这句话也可能自然。 |
| “它把杯子往胸口收了收” | 在 AI 角色扮演台词里插入现成的戒备/退缩肢体动作，让角色显得在现场；杯子缺少前文铺垫、动作也不推动情节，像自动配上的舞台说明。 | 如果杯子已在场、动作表明人物意图或带来后果，则可能是有效描写。 |
| “这句是AI当场接的，设定咬得死死的” | “当场接的”与“咬得死死的”像两段流行口语硬拼的宣传式评语；用一句拒绝回答就宣布设定稳定，还叠加夸张动词。 | “接话”“咬住设定”在具体社群语境中可能自然，不能逐词封禁。 |

## 另一种模式：伪生活体验的产品推广稿

常见顺序：自称长期玩家 → 旧方案痛点逐项列举 → “偶然发现”未点名的新工具 → 通过具体剧情/试用小动作展示能力 → 一项项解决前面痛点 → 强调免费与低门槛 → 评论区引导。真实体验也可能这样写，但若连抱怨、口头禅、玩笑、具体小细节都与卖点严格对齐，就应怀疑文本被营销目的过度加工。

识别时不能只抓“AI高频词”：这类文本会刻意避免书面腔，转而密集使用“真费劲”“上头”“咬得死死的”“馋人”“折腾过”等碎片化口语。判断每个口语是否真的由该人的叙述需要引出，还是仅用于增加亲历感。尤其不要把“文风像AI”和“这是广告/AI生成”混成同一个定论。

## 真实口语的边界

- “我坐不住了”“忍不住一点”“我有点受不了了”是某些自然口语的可能写法，**不是固定替换模板**。不能把所有“有点坐不住”批量改成同一句。
- “贵是贵，但是吃着还行”“不接了不接了”这种重复、口头转折、自然毛刺可能真实；不要主动往每句里添加“呃”“就”“那个”或网络流行语以表演真人。
- 可以开玩笑、抬杠、含混、停住；但不能保证每句都俏皮、都观点鲜明、都令人感动。

## 修正原则

- “不到三个星期。比我上一次年假还短。”如无特殊停顿需要，可直接写“不到三个星期，比我上一次年假还短。”
- 对“减量，不是增量。花一次少一次”，可删掉多余金句；如仍需表达，用正常语言“以后可能也就见这么多次了”，不要创造“人生从来不是拥有，而是倒计时”等新口号。
- 对“补一句漂亮的，手痒”，直接删除这个多余自嘲比替换成“忍不住抖机灵”更好。

## 新案例如何入库

保留以下四样就够：**原句 / 出现场景 / 不自然的具体原因 / 容易误伤的正常用法**。可以记录模型版本或日期，但不依据句式声称能鉴别作者身份。

遇到新案例优先更新这里；若出现一种稳定的新机制，再抽象成 SKILL.md 的原则。不要无限堆禁词。
